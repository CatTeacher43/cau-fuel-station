# 农大运动食补站

面向中国农业大学东、西校区学生的练后晚餐推荐工具。回答一个问题：**今天练完，在学校食堂吃什么？**

填完 6 个选项，输出 2–3 套「主食 + 蛋白 + 配菜」组合，并给出食堂位置、供应时段、营养估算和选择理由。无需注册，收藏保存在本地。

## 快速开始

纯静态页面，没有构建步骤和第三方依赖。

```bash
# 方式一：直接打开
# 双击 index.html 即可

# 方式二：本地服务器（推荐，便于手机同网访问）
cd E:/homework/11
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000
```


## 功能

- **30 秒问卷**：校区、训练目标、运动类型、训练时长、忌口/过敏、今晚口味。
- **2–3 套组合**：每个组合包含主食、蛋白、配菜，来自同一食堂，显示档口与参考价格。
- **真实食堂场景**：11 个校内食堂，按北京时间和各档口营业时段计算「正在供餐 / 晚餐几点开餐 / 今日已收档」。
- **目标化营养**：减脂、增肌、维持体重、恢复体力分别有热量、蛋白、碳水、脂肪目标区间。
- **严格忌口过滤**：不吃辣、素食（蛋奶可）、不吃牛/羊/猪肉、海鲜过敏；过滤同时作用于推荐与避雷提示。
- **解释与科普**：每套组合说明蛋白质、碳水与训练目标的匹配关系；提供练后时机、份量和目标建议。
- **避雷提示**：高油、高糖、重口菜品单独标注，并说明不推荐原因。
- **换一批**：轮换食堂组合，避免每天都是同一套。
- **本地收藏**：收藏、查看、移除晚餐组合，刷新后仍保留（`localStorage`）。
- **响应式与无障碍**：桌面双栏、移动端单栏；表单使用 `aria-pressed`，结果区 `aria-live`，收藏抽屉支持焦点管理和 Escape 关闭。

## 推荐逻辑

1. 按目标生成基础营养区间，并根据训练类型和时长修正。
2. 按校区、忌口、过敏与避雷标记过滤菜品。
3. 在每个食堂内枚举「主食 × 蛋白 × 配菜」，按蛋白/碳水/脂肪/热量偏离目标的程度打分。
4. 叠加目标偏好、少油、面食、营业状态、价格、全素等权重。
5. 每个食堂保留最佳组合，再选出 3 个不同食堂；`换一批` 通过旋转食堂队列改变组合。
6. 对每套组合生成标签、适配分、推荐理由和避雷项。

所有逻辑在 `assets/engine.js`，不依赖 DOM，可在 Node 中直接测试。

## 数据说明

食堂名称、楼层和营业时段参考中国农业大学公开餐饮资料整理；菜品、份量、价格和营养数值是**原型演示用的常见估计值**，不是食堂官方营养表。实际供应、价格和时段可能临时调整，请以现场为准。本项目不构成医疗或营养处方建议。
